Đã sửa theo yêu cầu
⧉ Nút chép — chỉ ký tự, bỏ chữ “Chép”, ô vuông 26px cùng hàng với mã.
Tên bưu tá — bỏ nhãn “BƯU TÁ”, in đậm tên ngay dưới trạng thái.
↳ Nguyên nhân — ghi chú kiện vấn đề nằm ngay dưới tên, thụt vào bằng ký tự ↳.
3 theme — chỉ đổi màu nền/viền; bo góc 6px và mật độ chữ bám theo app thật.
Màu vàng của dòng Newbie giữ nguyên ở cả 3 theme để nhân viên mới nhận ra ngay dù đổi theme.
