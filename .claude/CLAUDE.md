# Skills trong `.claude/skills/`

- **graphify** (`.claude/skills/graphify/SKILL.md`) — biến code/docs/ảnh thành knowledge graph.
  Trigger: `/graphify`.

Đây là skill **chạy theo yêu cầu**, không phải mặc định. Cho câu hỏi code thường ngày, `.codegraph/`
mới là mặc định. Ràng buộc đầy đủ: [.agent/rules/10-plugin-stack-rules.md](../.agent/rules/10-plugin-stack-rules.md) §4.

Hướng dẫn chính của dự án nằm ở [CLAUDE.md](../CLAUDE.md) và [AGENTS.md](../AGENTS.md) ở gốc repo —
file này không override chúng.
